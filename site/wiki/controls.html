Gamepad

The key hints show along the bottom of the screen while a pad is in use:

  • On a job: A select B back X run Back speed Y tag LB/RB parts Start menu
  • In menus: D-pad move A select B back
  • Surveying a line: D-pad move A yard / bend Y jump to the far yard B undo LS pan
  • Placing a transformer: D-pad pick a yard A place B cancel

Touch

One finger pans the map and a tap acts like a click. Two fingers pinch to zoom and turn. Touch has not been checked on a phone in recent releases.
